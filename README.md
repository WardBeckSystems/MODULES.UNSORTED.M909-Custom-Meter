| **Weight** | 525 grams (19 ounces). GENERAL M909 METER/MIX MINUS MODULE The M909 Meter/Mix Minus module provides source selection and buffering for the meters in the console system. In addition, the module can generate up to four mix-minus outputs from the console. Five meter buffers are included in the module. Two of these are permanently assigned to monitor a stereo program feed; normally console Program 1. One meter has a six button pre-selector associated with it. The remaining two buffers have an additional six button pre-selector for utilization as a auxiliary stereo metering system. All meter inputs are actively balanced. All audio is selected through solid-state logic controlled switches. Mix minus feeds are generated in the M909 too. to use the mix minus outputs, the mix minus buss in the console is assigned to all input channels except the telephones. The mix minus output from the M907 is connected to the balanced telephone input of the M909. Each telephone input module's post fader direct output (M901) is brought to the M909 individually. The appropriate mix minus feeds are generated internal to the M909 for use by up to four telephone hybrids. OPERATIONAL DESCRIPTION M909 METER/MIX MINUS MODULE Please refer to module layout drawing A 909-04-002.1) Legend Strips Two plastic covered designation strips for identification of the selector functions for the mono and stereo meter selectors. 2) Mono Meter Selector Momentary switches SW7 through SW12 control the active solid-state switches for source selection to the mono meter. 3) Auxiliary Stereo Selector Momentary switches SW1 through SW6 control the active solid-state switches for source selection to the left and right auxiliary meters. Meter Amplifiers Main Meter Amplifier Two identical meter amplifiers are employed for the main metering in the console. They consist of U28 and U29 and associated components for the left and right meters. Dual operational amplifier U28 forms the nucleus of a balanced input/balanced output variable sensitivity buffer. Capacitors C74 and C75 prevent external bias from disturbing the meter circuit, while C82 and C83 protect the meter from any offset error present in U28. Trim control R129 is normally factory set to provide a 0 VU indication on the console meters at the specified system levels. Resistor R135 ensures the output impedance of the meter amplifier matches the VU standard (ANSI C16.5-1954). Mono and Auxiliary Meter Selectors The mono and auxiliary meters have six input sources, of which only one maybe selected at a time. Referring to the schematic on sheet B909-02-002/2, each input is AC coupled to a separate 74HC4053 solid state switch. The outputs of the switches for the mono meter are all connected to the balanced summing amplifier U13. R46, R48 and R52 makeup the `T' feedback for U13A with potentiometer R52 providing the gain adjustment for the mono meter output. The left and right haves of the auxiliary stereo meter selector are identical to the mono meter selector. Meter Select Logic Refer to the schematic on sheet B909-02-002/1. The 74HC4053 switches are controlled by logic chips U1 through U6. Since both the mono and auxiliary stereo logic circuits are identical, only the mono meter selector will be described. Microcontroller U1 reads the switches SW7 through SW12, which are software debounced, and outputs a 3 bit binary code for the depressed switch with the highest precedence. The clock rate for U1 is set by the RC time constant of R11 and C7. U1 also requires a power on reset signal and this is provided by R17 and C5. The tally LEDs for switches SW7 through SW12 are controlled by U4, a CD4051 8 channel analog multiplexer. The three bit binary code from U1 determines which channel of U4 is turned &quot;ON&quot;. Current flows through current limiting resistor R19 and through the &quot;ON&quot; channel of U4 to the appropriate LED. Grounding the control line on pins 9, 10 &amp; 11 of the 74HC4053 will connect the associated input to the summing amplifier. The 8 channel analog multiplexer U3 operates in manner similar to U4 except that the &quot;ON&quot; channel of U3 grounds one of the control lines to the 74HC4053 switches. The remaining control lines are pulled up by R18, which turns off the remaining 74HC4053 switches for the mono selector. Mix Minus Refer to the schematic on sheet B909-02-002/3. The mix minus portion of the M909 consists of U30 through U34 and associated components. The telephone input is configured as a simple differential input amplifier whose signal is summed with all four mix minus outputs. The mix minus inputs are configured so that the like numbered output does not receive the associated input. Each mix minus output is electronically balanced for direct coupling to abridging output load. Power Supply Decoupling The active decoupling network consisting of Q1 through Q5 and associated components regulates the incoming power for use in the module. Diodes CR1 and CR2 prevent module damage in the event of power supply voltage reversal. The decoupling network drops the ±23 volts down to a nominal ±18 volts. Transistor Q3 further decouples the ±18 volts down to +5 volts for use by the CMOS logic circuitry.
